CLONE REPO:
git clone https://github.com/S1haam/CST2550-Driving-Lesson-Booking-System.git

Navigate into project:
cd CST2550-Driving-Lesson-Booking-System

Switch to correct branch:
git checkout integrate-admin-feature

Pull latest version:
git pull

Navigate into App folder:
cd src
cd DrivingLessonApp

Restore dependencies:
dotnet restore

Run project:
dotnet run

Open in browser:
http://localhost:5014
